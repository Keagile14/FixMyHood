# FixMyHood 🏘️

### Your Community. Your Voice. Your Change.

## 📌 About the Project

FixMyHood is a community-driven infrastructure reporting platform that allows residents to report problems affecting their neighbourhoods.

The platform aims to make it easier for community members to identify, report and track local infrastructure issues while promoting transparency and accountability.

Instead of struggling to find the correct department or contact person, residents can use one central platform to submit reports and monitor their progress.

## 🎯 Problem Statement

Many communities experience infrastructure challenges such as:

- Potholes and damaged roads.
- Broken or non-functional streetlights.
- Water leaks and burst pipes.
- Illegal dumping and waste management issues.
- Blocked drainage systems.

Residents often struggle to report these problems and receive feedback about whether they are being addressed.

FixMyHood aims to provide a centralised digital solution that makes this process more accessible and transparent.

## 💡 Project Objectives

1. Provide residents with an accessible platform to report community infrastructure problems.
2. Allow users to upload photographs and provide location details.
3. Enable residents to track the progress of their reports.
4. Provide administrators with a dashboard to manage and update submissions.
5. Encourage community participation and accountability.
6. Explore the use of AI to improve issue identification and reporting.

## ✨ Key Features

### Resident Features

- User registration and login.
- Report infrastructure problems.
- Select an issue category.
- Upload photographs as evidence.
- Provide the location of an issue.
- Track submitted reports.
- Receive status updates.
- View community-reported issues.

### Administrator Features

- Administrator dashboard.
- View and manage submitted reports.
- Review uploaded photographs.
- Update report statuses.
- Add progress notes.
- View reporting statistics and trends.

## 🤖 Future AI Integration

AI is a planned enhancement for FixMyHood.

Potential AI features include:

- **Image recognition:** Assist in identifying infrastructure problems from uploaded photographs.
- **Issue prioritisation:** Help flag potentially urgent reports for human review.
- **Data analysis:** Identify recurring infrastructure problems and patterns across communities.
- **AI assistant:** Help residents understand how to submit reports and use the platform.

## 🛠️ Technologies

The proposed technology stack includes:

- HTML – Website structure.
- CSS – Website styling and responsive design.
- JavaScript – Interactive functionality.
- Supabase – Database, authentication and image storage.
- Leaflet / OpenStreetMap – Interactive community maps.
- AI API – Future AI functionality.

## 🚀 Getting Started

### Prerequisites

To work on this project, you will need:

- A code editor such as Visual Studio Code.
- A web browser such as Google Chrome.
- Basic knowledge of HTML, CSS and JavaScript.

### Installation

1. Clone the repository:

   `git clone YOUR_REPOSITORY_URL`

2. Open the project folder in Visual Studio Code.

3. Open the `index.html` file in your browser or use the Live Server extension.

4. Follow the project setup instructions as backend functionality is introduced.

*Note: The repository URL and backend configuration will be added once the project has been set up.*
